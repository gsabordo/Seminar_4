Main takeaway

A network is not just about connecting devices. It must be designed and monitored so attackers cannot easily get in. Security is several layers: firewalls, network segmentation, secure configuration, and users who know what to avoid.

Where the industry is going

Cyber defense is becoming a regular part of IT work, not something added at the end. Teams are expected to build security into their systems from the start instead of fixing problems after an incident.

Link to cloud and DevOps

Cloud services and DevOps pipelines still run on networks, so they need the same practices: least-privilege access, multi-factor authentication, regular updates, and constant monitoring.

Personal reflection

Many of the accounts and Wi-Fi networks I use every day are protected only by weak habits, like reusing passwords.

Read the full narrative report

I only had a basic idea of how networking and security connect. Through the seminar I understood better how the two work together, and what stayed with me most was that security is never a single tool.

From what I learned, there are simple improvements that can be applied in real projects, including our own capstone and school systems. We can set up role-based access so that users only see what they need, enable multi-factor authentication on admin accounts, keep regular backups, and document the network setup so problems are easier to trace. For community projects, such as a barangay or small-office system, a short cybersecurity awareness session for staff could prevent many common mistakes like phishing.

Overall, this seminar made me more careful as a future IT professional and more interested in learning how to protect the systems I will build.
